# Cenfotec-2026-APIs-Proyecto
Este repositorio abarca la solución desarrollada como entregable final del curso de *Diseño e Implementación de APIs en .NET*, demostrando la aplicación de todos los conocimientos obtenidos durante el curso.

## Descripción
El proyecto, denominado *SymphonyAPI*, consiste en una API RESTful siguiendo los principios de Clean Architecture, que permite acceder al listado de artistas musicales y sus álbumes registrados en la base de datos de una tienda de música ficticia.

La solución presenta versionamiento, autenticación con JWT y API Keys y documentación mediante OpenAPI. Además incluye un gateway simple utilizando Ocelot y un Dockerfile para crear un contenedor con el API.

## Tecnologías y herramientas
* .NET 10
* SQL Server Express 2025
* Docker
